# Build of the Week — Edition 1: agent-browser

A browser tool your AI agent can drive: open pages, click, fill forms, read results.
From vercel-labs/agent-browser (see the repo for full docs).

## Install
- npm: `npm install -g agent-browser`
- Or Homebrew: `brew install agent-browser`

## First run (under an hour, no GPU)
1. Install with one command above.
2. Follow the Quickstart in the repo README: start the browser, open a test page, and run the sample commands (navigate, snapshot, click, type).
3. Point it at a page you know well. Compare what it reports with what you see.

## Watch-outs
- Read the repo README for current commands; the tool moves fast.
- Do not give it accounts or pages you cannot afford to have clicked through. Test on safe pages first.

Source: https://github.com/vercel-labs/agent-browser
