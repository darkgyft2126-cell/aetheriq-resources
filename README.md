# AetherIQ Weekly — Reader Resources

Files that belong to editions of **AetherIQ Weekly**, the LinkedIn newsletter that tracks the week's top AI signals, new models, trending repositories, and key papers.

## Layout
- `build-of-the-week/` — one folder per edition: the hands-on code or notebook from that week's build item.
- `downloads/` — free files that go with an edition (templates, cheat sheets). Polished PDF packs also live on Payhip as free products; the edition links both.

## Rule for links
Editions link curated repos and models at their original homes (GitHub and Hugging Face). Only files created for this newsletter live in this repo.
